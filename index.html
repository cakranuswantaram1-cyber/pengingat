Backup & Pulihkan Data

Semua data (pengingat, grup, riwayat, pengaturan) disimpan ke satu file bernama pengingat-backup.json. Di Chrome/Edge komputer, file yang sama otomatis ditimpa. Di HP, file diunduh dengan nama tetap.

File cadangan tidak terenkripsi. Jika berisi Brankas, simpan di tempat aman dan jangan dibagikan.
Aktifkan agar file cadangan tidak bisa dibaca tanpa kata sandi (AES-256-GCM). Kata sandi tidak disimpan; jika lupa, cadangan tidak bisa dibuka.

Pengaturan

Pisahkan dengan koma. Hanya tahap di dalam rentang peringatan tiap pengingat yang dipakai. Alarm berbunyi mulai H-7; tahap lebih awal hanya notifikasi.
Peringatan tahap (mis. H-30, H-7, H-1) baru berbunyi pada jam ini di hari tahap itu tercapai. Alarm saat lewat tempo tetap berbunyi tepat pada jam jatuh tempo.

Bantuan & Tentang

Pengingat Dokumen membantu memantau masa berlaku STNK, SIM, BPJS, tagihan, dan tanggal penting lainnya.

  • Tambah pengingat lewat tombol ➕, atur berapa hari sebelum jatuh tempo alarm berbunyi.
  • Pilih "Berulang" untuk tagihan bulanan atau dokumen tahunan.
  • Perlu Tindakan menampilkan yang sudah segera, mendesak, atau lewat tempo.
  • Data hanya tersimpan di perangkat ini. Rutin gunakan Backup & Pulihkan.
  • Brankas Dokumen menyimpan nomor STNK, SIM, KTP, polis, dan lainnya; isinya disembunyikan sampai kamu menampilkannya.
  • Daftar periksa per pengingat, Catat Pembayaran saat lunas, dan grafik pengeluaran di Ringkasan. Pengulangan bisa mingguan sampai 5 tahunan, atau kustom.
  • Tombol kembali tidak langsung keluar: akan muncul pilihan tetap di sini atau keluar.
  • Batalkan: setelah menghapus, menandai selesai, atau menjadwalkan ulang, ketuk "Batalkan" di bagian bawah layar dalam 7 detik.
  • Laporan PDF dan Kalender ada di menu samping.
  • Tunda & Jadwalkan Ulang: saat alarm berbunyi, ketuk Tunda untuk membunyikan lagi nanti, atau Jadwalkan Ulang untuk memindahkan tanggal jatuh tempo.
  • Enkripsi cadangan: centang di menu Backup & Pulihkan agar file cadangan dikunci kata sandi.
  • Keamanan & Kunci mengaktifkan PIN 6 digit dan sidik jari (butuh HTTPS). Jika lupa PIN, aplikasi harus direset.

Keamanan & Kunci

Jika terakhir verifikasi lebih dari 2 menit lalu, Brankas meminta PIN atau sidik jari lagi.

Kunci PIN mencegah orang lain yang memegang perangkatmu membuka aplikasi. Data tetap tersimpan di browser tanpa enkripsi, dan file cadangan hanya terenkripsi jika kamu mengaktifkannya di menu Backup & Pulihkan. Sidik jari diverifikasi oleh perangkatmu (WebAuthn) dan butuh HTTPS. Jika lupa PIN, satu-satunya jalan adalah reset yang menghapus semua data, jadi rutin simpan cadangan.
